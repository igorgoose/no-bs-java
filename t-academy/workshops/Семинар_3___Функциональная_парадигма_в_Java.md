### Базовый трек

**Пререквизиты:** `семинар 2` `лекция по функциональному программированию`

**Что делаем:** Подключаем заглушку внешнего API — приложение впервые начинает работать с данными. Разбираем лямбда-выражения и функциональные интерфейсы на примерах из проекта, сравниваем с анонимными классами. Вводим `Optional` как способ явно работать с отсутствием значения. Знакомимся с Generics: зачем нужны, как читать и писать generic-классы.

|  | **Состояние проекта** |
|---|---|
| **Начало** | CLI-парсер на паттерне Command; источника данных нет |
| **Конец** | Подключена заглушка API; в коде — лямбды, функциональные интерфейсы, `Optional` |

**Навыки:** `лямбда-выражения` `функции высшего порядка` `функциональные интерфейсы` `Optional` `Generics: основы` `extends и super`

### Advanced трек

**Пререквизиты:** `семинар 2 (advanced)` `лекция по функциональному программированию`

**Что делаем:** То же, что в базовом треке. Дополнительно смотрим, во что компилируются анонимный класс и лямбда — изучаем байт-код через `javac`. Знакомимся с Vavr: разбираем `Try` и `Either` как альтернативу исключениям.

|  | **Состояние проекта** |
|---|---|
| **Начало** | CLI-парсер на паттерне Command; источника данных нет |
| **Конец** | Всё то же, что в базовом треке + примеры с Vavr `Try` / `Either` |

**Навыки:** `лямбда-выражения` `функциональные интерфейсы` `Optional` `Generics` `байт-код лямбд` `Vavr: Try, Either`
