### Базовый трек

**Пререквизиты:** `семинар 4` `лекция по Java Collection Framework`

**Что делаем:** Заменяем заглушку API на in-memory хранилище — набор коллекций с инструментами и котировками. Смотрим на разные структуры данных и выбираем подходящие для каждой задачи. Замеряем производительность операций под нагрузкой.

|  | **Состояние проекта** |
|---|---|
| **Начало** | Заглушка API в виде простых объектов |
| **Конец** | In-memory хранилище на коллекциях; логика поиска и фильтрации через Collections API |

**Навыки:** `List, Set, Map: выбор структуры` `сложность операций` `Collections API` `сравнение производительности коллекций`

### Advanced трек

**Пререквизиты:** `семинар 4 (advanced)`

**Что делаем:** То же, что в базовом треке. Дополнительно разбираем высоконагруженные коллекции из FastUtils и смотрим на альтернативы из Vavr, Guava и Apache Commons.

|  | **Состояние проекта** |
|---|---|
| **Начало** | Заглушка API в виде простых объектов |
| **Конец** | Всё то же, что в базовом треке + сравнение с FastUtils; примеры из Guava / Vavr |

**Навыки:** `Java Collection Framework` `FastUtils` `Guava collections` `Vavr immutable collections` `выбор коллекции под задачу`
