## Семинар 4 — Обработка ошибок

### Базовый трек

**Пререквизиты:** `семинар 3` `лекция по обработке ошибок`

**Что делаем:** Разбираем, какие исключительные ситуации могут возникнуть при работе с API: нет сети, невалидный токен, rate limit, неожиданный ответ. Сравниваем подходы: коды ошибок vs исключения. Реализуем собственные исключения для проекта и добавляем корректную обработку ошибок в CLI.

|  | **Состояние проекта** |
|---|---|
| **Начало** | Заглушка API без обработки ошибок |
| **Конец** | Иерархия собственных исключений; try-catch в точках входа CLI; понятные сообщения об ошибках |

**Навыки:** `checked vs unchecked exceptions` `собственные исключения` `обработка ошибок API` `fail-fast vs fail-safe`

### Advanced трек

**Пререквизиты:** `семинар 3 (advanced)` `лекция по обработке ошибок`

**Что делаем:** То же, что в базовом треке. Дополнительно — измеряем накладные расходы от исключений с помощью JMH: строим бенчмарк и сравниваем производительность кода с исключениями и без.

|  | **Состояние проекта** |
|---|---|
| **Начало** | Заглушка API без обработки ошибок |
| **Конец** | Всё то же, что в базовом треке + JMH-бенчмарк с измерением оверхеда исключений |

**Навыки:** `checked vs unchecked exceptions` `собственные исключения` `JMH: основы` `измерение оверхеда исключений`
