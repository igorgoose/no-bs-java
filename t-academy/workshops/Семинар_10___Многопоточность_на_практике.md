### Базовый трек

**Пререквизиты:** `семинар 9` `лекция по основам многопоточности`

**Что делаем:** Добавляем фоновый шедулер, который периодически обновляет данные. Разбираем `ExecutorService` и `Future` — как запускать задачи, отслеживать выполнение и корректно прерывать. Добавляем синхронизацию там, где она нужна. Верхнеуровнево смотрим на concurrent-коллекции.

|  | **Состояние проекта** |
|---|---|
| **Начало** | Приложение работает синхронно, данные не обновляются в фоне |
| **Конец** | Фоновый шедулер обновления данных; корректное завершение потоков; concurrent-коллекции для разделяемого состояния |

**Навыки:** `ExecutorService` `Future` `прерывание потоков` `синхронизаторы` `concurrent collections`

### Advanced трек

**Пререквизиты:** `семинар 9 (advanced)`

**Что делаем:** То же, что в базовом треке. Дополнительно разбираем низкоуровневую работу с потоками: `wait` / `notify`, `monitor`, `synchronized`. Разбираем Java Memory Model, `volatile` и атомарные операции (CAS).

|  | **Состояние проекта** |
|---|---|
| **Начало** | Приложение работает синхронно |
| **Конец** | Всё то же, что в базовом треке + примеры с `synchronized` / `volatile` / `AtomicReference` |

**Навыки:** `ExecutorService` `wait / notify / monitor` `Java Memory Model` `volatile` `CAS / AtomicReference`
