### Базовый трек

**Пререквизиты:** `семинар 11` `лекция по высокоуровневым паттернам многопоточности`

**Что делаем:** Обзор важных JEP за последние несколько лет. Разбираем те, которые можно применить в нашем проекте прямо сейчас: Records, Sealed Classes, Pattern Matching, Structured Concurrency. Обновляем код там, где новые фичи делают его чище.

|  | **Состояние проекта** |
|---|---|
| **Начало** | Проект написан в стиле Java 8–11 |
| **Конец** | Доменные классы переведены на Records; применён Pattern Matching; добавлены Sealed Classes там, где есть иерархия |

**Навыки:** `Records` `Sealed Classes` `Pattern Matching` `Text Blocks` `Structured Concurrency` `обзор JEP`

### Advanced трек

**Пререквизиты:** `семинар 11 (advanced)`

**Что делаем:** То же, что в базовом треке. Дополнительно разбираем Project Loom: Virtual Threads — чем отличаются от обычных потоков, когда оправданы, как они могут изменить стриминг в нашем приложении.

|  | **Состояние проекта** |
|---|---|
| **Начало** | Проект написан в стиле Java 8–11 |
| **Конец** | Всё то же, что в базовом треке + стриминг переведён на Virtual Threads; сравнение производительности через JMH |

**Навыки:** `Records` `Sealed Classes` `Pattern Matching` `Virtual Threads (Project Loom)` `сравнение потоков через JMH`
