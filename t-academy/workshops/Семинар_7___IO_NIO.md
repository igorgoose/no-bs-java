### Базовый трек

**Пререквизиты:** `семинар 6` `лекция по IO/NIO`

**Что делаем:** Добавляем постоянное хранилище: watchlist и кеш котировок теперь живут в файловой системе. Заменяем заглушку API на полноценный клиент для T-Invest API. Разбираем эффективное чтение и запись файлов.

|  | **Состояние проекта** |
|---|---|
| **Начало** | In-memory хранилище; заглушка вместо реального API |
| **Конец** | Watchlist и кеш в файловой системе через NIO; приложение работает с реальными данными |

**Навыки:** `NIO: Path, Files, Channels` `чтение и запись файлов` `буферизация` `работа с реальным API`

### Advanced трек

**Пререквизиты:** `семинар 6 (advanced)`

**Что делаем:** То же, что в базовом треке. Дополнительно разбираем, как работает `Selector` внутри: разные реализации под разные ОС (kqueue, poll, epoll). Смотрим на `AsynchronousSocketChannel`.

|  | **Состояние проекта** |
|---|---|
| **Начало** | In-memory хранилище; заглушка вместо реального API |
| **Конец** | Всё то же, что в базовом треке + пример с `AsynchronousSocketChannel`; разбор Selector под капотом |

**Навыки:** `NIO Channels` `Selector` `kqueue / poll / epoll` `AsynchronousSocketChannel` `неблокирующий ввод-вывод`
